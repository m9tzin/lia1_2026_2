## Contribuição e commits

As contribuições devem utilizar o padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/). A mensagem deve seguir o formato:

```text
tipo(escopo opcional): descrição breve
```

Tipos recomendados:

- `feat`: adiciona uma nova funcionalidade ou entrega;
- `fix`: corrige um erro;
- `docs`: altera documentação;
- `refactor`: reorganiza o código sem alterar seu comportamento;
- `test`: adiciona ou modifica testes;
- `chore`: realiza tarefas de manutenção.

Exemplos:

```text
feat: adiciona a primeira entrega
docs: atualiza as instruções do README
fix: corrige a validação dos dados
```
